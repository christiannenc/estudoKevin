AVALIAÇÃO PRÁTICA: PRONOMES DEMONSTRATIVOS (POSIÇÃO E REFERENCIAÇÃO TEXTUAL)
💡 RELEMBRANDO A REGRA DOS PRONOMES DEMONSTRATIVOS:
• ESTE / ESTA / ISTO: Usado para o que está com quem fala (1ª pessoa) OU para indicar o elemento citado por último no texto.
• ESSE / ESSA / ISSO: Usado para o que está com a pessoa com quem se fala (2ª pessoa) OU para retomar algo já dito.
• AQUELE / AQUELA / AQUILO: Usado para o que está distante de ambos (3ª pessoa) OU para indicar o elemento citado em primeiro lugar.
